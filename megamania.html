Como jogar: é o cartucho original do Atari 2600 rodando num emulador, com a imagem e o som de verdade. Como no Atari, a partida só começa quando você aperta o Game Reset: use o botão Iniciar partida acima (também serve para recomeçar depois do fim de jogo). No computador, mova a nave com ← → e atire com espaço. F12 é o botão Game Reset (começa a partida) e F11 é o Game Select (troca o modo de jogo). No celular, toque em GO! para abrir em tela cheia com o controle na tela; lá, a partida começa tocando na chave GAME RESET (a da direita, no painel do Atari embaixo).
